# ADR-0003: グッズ画像を非公開の Cloudflare R2 に保存する

## Status

Accepted

記録日：2026-11-24

## Context

本人が撮った画像と公式商品ページの URL を同じグッズに紐付けたい。グッズ一覧の検索は主に分類や所持数を対象とする。

## Decision

画像本体は非公開の Cloudflare R2 に置く。PostgreSQL には画像を参照するオブジェクトキーと、公式商品ページの URL を別々に記録する。

## Consequences

- 画像容量を検索用 DB と独立して管理できる。運用時は R2 の利用量も確認する。
- 画像の登録・閲覧には所有者の確認が必要になる。R2 への保存後に DB の登録が失敗した場合は、参照されない画像を処理する必要がある。
- 画像の転送方式は API 経由または短命の署名付き URL が候補。[画像の取り扱い](../04_architecture.md)

## Alternatives

**画像本体を PostgreSQL に保存する案（設計条件に基づく比較）**。グッズと画像を同じトランザクションで保存できる。写真の追加に伴って DB 容量とバックアップサイズが増えるため、初期版では画像本体をオブジェクトストレージに置く方針を採った。
