# features.md

## 1. グッズ管理（CRUD）

グッズの登録・閲覧・編集・削除を行う基本機能。

### 属性

| 属性名 | 型 | 備考 |
|---|---|---|
| 名前 | テキスト | 必須 |
| キャラ名 | テキスト | 複数設定可 |
| 種類 | 選択肢 | バッジ・アクキーなど |
| 個数 | 数値 | 所持数 |
| 発売年 | 数値（年） | |
| 外部サイトURL | URL | 商品ページなど |
| 画像 | 画像ファイル | 複数枚対応を想定 |

将来的にはユーザーが属性を自由に管理できるようにする。

---

## 2. 一覧・詳細表示

グッズを画像付きで見やすく閲覧する。

- グリッド表示（画像サムネイル一覧）
- リスト表示（属性を並べて比較しやすい形）
- グッズ詳細ページ（全属性 + 画像を表示）

---

## 3. 属性検索・絞り込み

ユーザーが決めた属性でグッズを絞り込む。フォルダ階層の代替となる中心機能。

- キャラ名・種類でフィルタリング
- 複数条件を AND で絞り込む
- フリーワード検索（名前・キャラ名を対象）

---

## 4. 個数管理

グッズの所持数と収集目標数を記録・表示する。

- 所持数（現在何個持っているか）を登録・更新
- 目標数（何個集めたいか）を登録
- 一覧画面で所持数を表示

---

## 5. 収集達成率の表示

目標に対してどのくらい集まったかをパーセントで可視化する。

- グッズ単体：所持数 ÷ 目標数 でパーセント表示
- 全体サマリー：登録グッズ全体の達成率をダッシュボードに表示

---

## スコープ外

- ユーザー認証・複数アカウント対応
- グッズの売買・トレード機能
- 他ユーザーとのコレクション共有
- カスタム属性の追加
