## 未決事項

- DB アクセスライブラリとマイグレーションツールは、絞り込み・集計の SQL を読みやすく管理できるかで選ぶ。
- 初期開発はローカルで行う。クラウド配信先は未定。外出先から使えるようにする際は Next.js のサーバー処理が動く環境を選び、DB・画像・配信の無料枠と超過時の挙動を確認する。
- 検索・保存の独立配信が必要になった場合、Go は移行先の候補とする。判断基準と切り出し手順は [アーキテクチャ](04_architecture.md) を参照。
